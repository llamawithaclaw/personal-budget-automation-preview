Monthly workflow quick guide — optional
  1. Select the report month.
  2. Import bank/card CSVs using the closest preset.
  3. Review uncategorized transactions and assign class/category.
  4. Update category targets and debt payoff inputs if needed.
  5. Import last month’s snapshot/profile for comparisons.
  6. Generate PDF / Print, then export profile and monthly snapshot privately.

Keep real CSVs, profiles, and PDFs private. Do not commit them to git.
